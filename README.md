# decaymem

**Память, которая решает, что забыть.**

Векторные базы отвечают на вопрос «как найти нужное». decaymem отвечает на
другой: «что вообще стоило хранить». Запись происходит не на каждое
сообщение, а когда эмоция или ошибка предсказания переваливают порог;
сохранённое угасает со временем и укрепляется тем, что пригодилось.

```python
from decaymem import Memory

memory = Memory("brain.db")

memory.observe("меня зовут Паша", "приятно познакомиться", emotion=0.4)
memory.feedback(+1.0)                       # пользователь одобрил — закрепить
memory.recall("как меня зовут")             # -> [MemoryMatch(...)]
memory.context_for("как меня зовут")        # -> текст для промпта
memory.forget()                             # провести угасание на сейчас
```

Установка: `pip install decay-memory` (имя свободно, публикации пока не
было). Зависимостей нет — стандартная библиотека и sqlite3, колесо весит
74 КБ.

**Язык задаётся кодировщиком, а не библиотекой.** Встроенный — navec,
русские статические векторы (51 МБ, без torch). Для английского или
любого другого передайте свою функцию:

```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("all-MiniLM-L6-v2")
memory = Memory("brain.db", encoder=lambda text: model.encode(text))
```

Кодировщиком может быть что угодно, возвращающее числа или `None`:
локальная модель, вызов API, fastText. Без кодировщика поиск идёт по
строковому сходству и продолжает работать.

## Что измерено

Все числа получены стендами из этого же репозитория, на пяти сидах, и
воспроизводятся побайтово.

**Забывание избирательно по важности, которую задаёт пользователь.**
После двух недель молчания (`tools/compare_retention.py`):

| Хранилище | Похвалённое | Обычное | Разрыв |
|---|---|---|---|
| Скользящее окно | 70% | 73% | −3% |
| Случайный отбор | 57% | 67% | −10% |
| **decaymem** | **100%** | **47%** | **+53 п.п.** |

С контролем на объём (обе группы дают поровну сообщений) разрыв растёт
до +67 п.п. У наивных хранилищ он около нуля — они про оценку
пользователя ничего не знают.

**Организм перестаёт удивляться привычному.** На потоке из 120 сообщений
удивление падает 0.750 → 0.278, а спайки вслед за ним 9 → 0. Это и есть
экономия: на тысячном сообщении рутина уже не пишется.

**Сжатие.** 15–27 эпизодов из 120 обменов в зависимости от сида, текста
примерно втрое меньше исходного потока.

### Чего decaymem НЕ делает

**Он не лучше случайной выборки на равномерных вопросах.**
`tools/compare_memory.py`, те же пять сидов, равный бюджет в символах:

| Хранилище | Найдено |
|---|---|
| Скользящее окно | 86.8% |
| Случайный отбор | **88.8%** |
| decaymem | 87.2% |

Случайный отбор впереди, и это ожидаемо: против равномерных вопросов
несмещённый отбор непобедим по построению, а любой осмысленный отбор
смещён. decaymem проигрывает ровно там, где его смещение и есть смысл.

Нужна полнота поиска — берите векторную базу. decaymem про удержание
важного, а не про «не потерять ничего».

## Как это устроено

| Механизм | Что делает |
|---|---|
| **Спайк-гейт** | Пишет, когда `(эмоция + удивление) / 2 >= порог`. Порог поднимается под нагрузкой. |
| **Собственное удивление** | Ошибка предсказания по своему графу слов и их сочетаний, а не энтропия строки. Опыт снижает её. |
| **Два параметра памяти** | `weight` — насколько ярко помнится сейчас; `stability` — насколько медленно забывается. Стабильность растёт при каждом вспоминании. |
| **Дофамин** | Подкрепление по ошибке предсказания награды (Рескорла-Вагнер): ожидаемая похвала почти не двигает вес, неожиданная двигает сильно. |
| **Вытеснение** | Противоречие с известным — самостоятельный повод записать. Устаревшая версия ослабляется, а не удаляется. |

**Скорость.** Поиск линейный по числу узлов, но дорогое нечёткое
сравнение считается только для лучших кандидатов из дешёвого отбора —
профилировщик показал, что оно съедало 82% времени. Замер на одной
машине:

| узлов | было | стало |
|---|---|---|
| 500 | 32 мс | 7 мс |
| 10 000 | 655 мс | 177 мс |
| 30 000 | 2 074 мс | 503 мс |

Размер запаса кандидатов настраивается; поставить его больше числа узлов
означает вернуться к полному перебору. Тест сверяет, что отбор не меняет
выдачу.

Время приходит извне: все методы принимают `timestamp`, часы
подменяются через `clock=`. Забывание считается по этой шкале, поэтому
она должна быть одна и монотонная.

```python
now = [1000.0]
memory = Memory("brain.db", clock=lambda: now[0])
now[0] += 30 * 86400          # промотать месяц
memory.forget()
```

Настройки — датакласс, а не глобальный конфиг:

```python
from decaymem import Memory, MemorySettings
memory = Memory("brain.db", settings=MemorySettings(decay_rate=0.02, age_t0=3600))
```

## Что ещё в репозитории

Кроме пакета здесь лежит **демонстрация** — телеграм-бот, который
начинает с лепета и постепенно осваивает речь, мини-приложение с графом
памяти и измерительные стенды. Это витрина и полигон, а не часть
библиотеки: в дистрибутив едет только `decaymem/`.

```
decaymem/     пакет памяти — единственное, что ставится через pip
core/       персонаж: настроение, инстинкты, речевые стадии, самообраз
tools/      стенды: обучение, удержание, покрытие, инспектор памяти
tests/      265 тестов
AUDIT.md    что измерено, что опровергнуто, что не сделано
```
