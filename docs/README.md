# Страница проекта

`index.html` — то, что GitHub Pages отдаёт по адресу
`https://merumez.github.io/selective-memory/`.

Она **самодостаточна**: ни одного внешнего запроса, все документы внутри.
Открывается локально, отправляется вложением, работает без сети.

## Что на ней

Что это и числа · настоящий вывод `tools/demo.py` · как устроено · числа с
командами, которыми они воспроизводятся · таблица измеренного и
отвергнутого · четыре истории · полные документы свёрнутыми.

## Пересобрать

```bash
python tools/build_page.py
```

Собирается ИЗ ФАЙЛОВ репозитория, а не пишется руками — иначе страница
разойдётся с документами молча. Это уже случалось: числа облегчённого
набора простояли в README как заявка о качестве, пока прогон на полном не
показал разницу в тридцать пунктов.

`--no-demo` пропускает прогон демонстрации, если некогда ждать модель.
